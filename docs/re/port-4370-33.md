# Port 157.0.4341.60 -> 158.0.4370.33

Done by static analysis (no public PDB for either build): four passes wrote
`app/dll/out/port158/*.tsv`; every high and medium row went into `offsets.h`.
Two entries the passes never listed were found by byte signature:
`BrowserWebContentsDelegate_ShouldOverrideNewWindowCreation` 0xfd8d1b0 and
`EdgeTabStrip_UpdateDropShadow_splitMemberPath_return` 0xa34df76 (medium: a unique
match, the function's hot and cold parts agree). Two low rows were promoted by
hand: `SplitWindowControlMenu_PopulateMenu` 0xfe735fe (called right after
BuildMenuModel in the same caller, same prologue) and `EdgeTab_vftable`
0x125b0178 (referenced by two functions of the same sizes as the 157 ones, 1257
and 520 bytes).

Code changes: Tab_IsActive's controller slot is 0x1f0 (was 0x1f8);
OnCooldownEnded's inlined StopCapture copy runs on rsi (`INLINEDSTOP_tail_rsi`).
Entries listed in `unplaced::kRvas` keep their 157 value, translate to null and
clear their features even on the pinned build (`kUnplacedFeatures`).

Comments in `offsets.h` that quote a function's RVA (not an entry) are still 157's.
