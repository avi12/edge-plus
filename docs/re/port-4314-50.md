containing function, with equal function sizes everywhere (no `size changed`
entry), and the old `.42` image (kept in the symbol cache) confirmed the first
instructions. Nothing but addresses moved: most are `+0x1000` (data) or
`+0x1100`..`+0x1b80` (code); the public PDB has no types, so equal sizes plus
