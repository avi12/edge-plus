# Porting the offsets: 155.0.4283.62 -> 156.0.4314.42

A major update. `port_offsets.py` placed 224 of 260 RVAs by symbol with equal
sizes; the rest were checked by disassembling old (`.62`, kept in the symbol
cache since Edge deletes it) against new, and 18 overridden by hand (`manual`
below). The public PDB has no types, so every `off::` constant was re-derived
from the function that reads it in both builds.

## What changed beyond addresses

| what | old | new | evidence / code change |
|---|---|---|---|
| `views::ProposedLayout` | `{Size; std::vector<ChildLayout>}`, 0x20 | `{Size; absl::InlinedVector<ChildLayout, 8>}`, 0x190 | `ApplyLayout`; size word at +8 (count << 1, bit 0 = on the heap), entries inline at +0x10 or pointed to from there. `ChildLayouts_emplace_back` is now the absl `Storage::EmplaceBack`, same arguments. `ProposedChildBounds` and `kProposedLayoutBytes` follow |
| `SendPageContextualPromptToChat` | 5 args | 6 args, and the prompt argument is filtered to a short alphanumeric code | the DLL now calls `SendPageContextualPromptToChatImpl` (unfiltered) with an empty account string |

| `ASKREQUEST_size` | 0x140 | 0x160 | ctor/dtor: a new optional<string> at +0x140 |
| `BV_multi_contents_view` / `BV_browser` | 0x6e0 / 0x600 | 0x6f8 / 0x618 | `BrowserView::ShowSplitView`, `MaybeUpdateSplitView`, the MCV ctor |
| `TABCOLL_count` | 0x18 | 0x20 | `TabStripModel::count` |

| a11y pane label ids (comment) | 0x3e62 / 0x3e63 | 0x3e89 / 0x3e8a | `tabs::GetAccessibleTabLabel` |

Not found changed: every other `off::` constant (about 210), `kScriptWorldId`,
the `optional<SplitTabId>` flag in `split_data.h`, the `kRRect*` in
`tab_shape.h`. `COLORMODE_light/dark` were not re-checked.

## Live run (a throwaway Edge, `--user-data-dir` with `edgeplus-port156-`, its own LOCALAPPDATA)

Every hook logged `[ok]` (42 plus the assistant, find, theme-follow and live
preview groups), `verify.h` accepted the three patch sites (`2`, `0F 85`,
`0F 83`), and a 4-pane split built through the control channel (code 204) and
tiled 4/4 with grips, control buttons and dividers. Not driven: find, Ask
Copilot (its prompt path changed, see above), theme swap with a theme
installed, the ⋯ menu, tab drag, links.
